## Contributing

Thank you for your interest in contributing to this project! All contributions are welcome. To get started, please follow these steps:

### How to Contribute:

1. **Fork the repository**
2. Click on the "Fork" button at the top right of this repository to create your own copy of this project.
   
3. **Clone your fork**:
- Clone your fork to your local machine using the following command:
     ```
     git clone https://github.com/YOUR_USERNAME/WiFi-Doorbell-Notifier-ESP8266-Telegram.git
     ```
   
4. **Create a branch**:
- Create a new branch for your changes:
     ```
     git checkout -b your-feature-branch
     ```

5. **Make your changes**:
- Edit or add any code, documentation, or enhancements.

6. **Commit your changes**:
- After making your changes, commit them with a clear message:
     ```
     git commit -m "Added feature XYZ"
     ```

7. **Push to your fork**:
- Push your changes back to your forked repository:
     ```
     git push origin your-feature-branch
     ```

8. **Create a Pull Request**:
- Open a pull request from your forked repository to this original repository.

### Code of Conduct
Please follow the **[Code of Conduct](CODE_OF_CONDUCT.md)** for a respectful and productive environment.
